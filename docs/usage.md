# 사용법

## 처음 설정

1. `firmware/cfg.toml.example`을 `firmware/cfg.toml`로 복사하고 Wi-Fi 이름과 비밀번호, 날씨를 볼 위치(위도·경도)를 채운다. 이 파일은 `.gitignore`에 들어 있어 커밋되지 않는다.
2. `cd firmware && cargo run`으로 빌드해서 올린다. 설정은 빌드할 때 펌웨어에 들어가므로, 바꾼 뒤에는 다시 빌드해서 올려야 한다.

- ESP32-C3는 2.4GHz Wi-Fi만 지원한다. WPA2 개인 네트워크나 비밀번호 없는 네트워크를 쓴다.
- `cfg.toml` 없이 빌드하면 화면에 `NO WIFI CFG`가 나오고 시각은 `--:--`로 남는다.

## 화면

USB 단자를 아래로 두고 본다. K1로 두 화면을 오간다.

| 화면 | 내용 |
|---|---|
| 시계 (켜면 이 화면) | 위: 날짜와 요일, Wi-Fi 상태 점 / 가운데: 시각 (콜론이 1초마다 깜빡임) / 아래: 날씨 아이콘, 기온, 습도 |
| 날씨 자세히 | 기온(소수 첫째 자리), 날씨 이름, 오늘 최고·최저 기온, 습도, 풍속, 마지막으로 받은 시각 |

오른쪽 위 Wi-Fi 상태 점:

| 색 | 의미 |
|---|---|
| 🟢 초록 | 연결됨 |
| 🟡 노랑 | 연결하는 중 |
| 🔴 빨강 | 연결 실패. 10초마다 다시 시도한다 |
| ⚪ 회색 | `cfg.toml`에 Wi-Fi 설정이 없다 |

날씨를 아직 받지 못했을 때는 날씨 자리에 상태 문구가 나온다: `NO WIFI CFG`, `CONNECTING`, `WIFI FAILED`, `LOADING`, `WEATHER FAIL`. 한 번 받은 뒤 갱신에 실패하면 마지막 값을 그대로 보여 주면서 시계 화면에 주황색 `!`, 날씨 자세히 화면에 `UPDATE FAILED`를 표시한다.

## 버튼

| 버튼 | 동작 |
|---|---|
| K1 | 시계 화면 ↔ 날씨 자세히 화면 |
| K2 | 날씨를 바로 다시 받는다 |
| K2를 누른 채 켜기 또는 RESET | 하드웨어 점검 모드: 색 점검, 화면 방향·오프셋, 버튼·LED 확인 |
| RESET | 다시 시작 |
| BOOT를 누른 채 RESET | 다운로드 모드 (플래시가 잘 안 될 때) |

빨간 LED는 Wi-Fi가 연결되기 전까지 깜빡이고, 연결되면 꺼진다.

## 하드웨어 점검 모드

K2를 누른 채 켜거나 RESET하면 들어간다. LCD 색 점검(RED → GREEN → BLUE → WHITE → BLACK)을 한 뒤 테두리, 위쪽 화살표, 버튼 상태 칸, 펌웨어 버전이 있는 점검 화면을 띄우고, 빨간 LED를 1초 주기로 깜빡인다. 다시 시작하면 시계로 돌아간다.

| 점검 항목 | 정상 | 아니면 |
|---|---|---|
| 색 점검 | 배경색이 가운데 글자(RED 등)와 같다 | 색 반전(`invert_colors`)이나 색 순서(`color_order`)를 고친다 |
| 테두리 | 네 변 모두 1px 흰 선이 보인다 | `LCD_OFFSET`을 고친다 |
| 화살표 | USB 단자를 아래로 두고 쥐었을 때 위를 가리키고 글자가 똑바로 읽힌다 | `LCD_ORIENTATION`을 고친다 ([LCD](hardware.md#lcd)) |
| 버튼 칸 | K1·K2·BOOT를 누르면 해당 칸이 초록이 된다 | 핀 배치를 확인한다 |

## 시각과 날씨

- **시각**: Wi-Fi가 연결되면 SNTP(`pool.ntp.org`)로 맞추고, 이후 한 시간마다 다시 맞춘다. 한국 표준시(UTC+9)로 표시한다.
- **날씨**: [Open-Meteo](https://open-meteo.com/)에서 15분마다 받는다. 실패하면 1분 뒤 다시 시도한다. API 키는 필요 없다. 처음 받을 때는 시각이 맞춰질 때까지(최대 20초) 기다린다.
- **배터리**: 백라이트를 끌 수 없고 절전 기능이 없어서 배터리로는 오래 가지 않는다.
